# 06 — Data Science

**Stage:** Beginner foundations · **Prerequisites:** 02-03; 05 basics · **Estimate:** 30-50 hours

## Outcomes

Turn raw observations into trustworthy, documented datasets without leaking evaluation information or hiding data-quality issues.

## Planned lessons

Data lifecycle and schemas; NumPy/Pandas; loading and validation; missingness, outliers, and transformations; exploratory analysis and visualization; sampling; feature engineering; train/validation/test separation; leakage; provenance and reproducibility.

**Practice milestone:** publish a reproducible analysis of a public or synthetic dataset with caveats. **Status:** planned; no lessons completed.
