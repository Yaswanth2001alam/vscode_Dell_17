# 20 — Embeddings and Vector Databases

**Stage:** Advanced application · **Prerequisites:** 15-17 · **Estimate:** 20-35 hours

## Outcomes

Explain dense vector representations and similarity search, and measure retrieval rather than judging only by intuition.

## Planned lessons

Embedding objectives; cosine/dot-product/distance; normalization; indexing and approximate nearest neighbors; metadata filters; hybrid search; vector database design; retrieval metrics and privacy.

**Practice milestone:** implement a small local retrieval baseline and compare it with lexical search. **Status:** planned; local/free choices will be preferred where appropriate.
