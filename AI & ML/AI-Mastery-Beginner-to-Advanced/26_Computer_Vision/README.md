# 26 — Computer Vision

**Stage:** Advanced specialization · **Prerequisites:** 12-14 · **Estimate:** 30-50 hours

## Outcomes

Represent and evaluate image/video tasks, choose suitable architectures, and diagnose data and deployment issues.

## Planned lessons

Image arrays and transforms; convolution; classification; detection; segmentation; transfer learning; augmentation; metrics; robustness, bias, and inference constraints.

**Practice milestone:** train/evaluate a small image baseline with documented data provenance and error review. **Status:** planned; dataset access and hardware guidance to follow.
