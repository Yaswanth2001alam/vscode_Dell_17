# Lesson 01 Examples

Python 3.11+; standard library only.

- `ai_categories.py`: explicit threshold rule versus a learned nearest-centroid model.
- `tiny_classifier.py`: fit, predict, and calculate accuracy for a tiny numeric example.

Run both from the repository root using the commands in the [root README](../../README.md). Each script prints deterministic sample output and a warning about the toy data's limitations.

## Network triage design exercise

Use the lesson's mini-project prompt to design a read-only telemetry triage pipeline. No device integration or configuration changes are implemented in this lesson. Later project code should use generated/sanitized inputs, explicit tests, and human authorization for any potentially disruptive operation.
