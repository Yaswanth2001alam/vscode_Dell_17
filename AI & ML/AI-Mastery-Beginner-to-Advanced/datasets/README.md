# Course Datasets

Use small synthetic or public datasets with documented provenance, license/terms, schema, and any transformations. The course will prefer bundled synthetic fixtures for reproducible beginner lessons; larger datasets should have explicit download instructions and should not be committed without checking their terms.

Never store credentials, private customer records, raw production logs, or unreviewed network configurations here. `raw/` and `private/` are ignored by Git; that ignore rule is a guardrail, not a substitute for access control.
