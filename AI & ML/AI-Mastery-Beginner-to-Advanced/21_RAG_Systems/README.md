# 21 — Retrieval-Augmented Generation Systems

**Stage:** Advanced application · **Prerequisites:** 20 · **Estimate:** 30-50 hours

## Outcomes

Design and evaluate a document-grounded answer system from ingestion through citations, including failure handling.

## Planned lessons

Document ingestion and parsing; chunking; metadata; embeddings; dense, lexical, and hybrid retrieval; reranking; grounded generation; citations; retrieval/answer evaluation; advanced RAG; access control and injection risks.

**Practice milestone:** build a local document assistant with source-linked answers, retrieval evaluation, and unanswerable-query tests. **Status:** planned.
