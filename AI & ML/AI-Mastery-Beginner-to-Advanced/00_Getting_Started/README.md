# 00 — Getting Started

**Stage:** Beginner foundations · **Prerequisites:** None · **Estimate:** 4-8 hours

## Outcomes

Set up Python 3.11+, VS Code, a terminal, Git, and an isolated virtual environment; run a script and its tests; understand the repository's lesson and progress conventions.

## Planned lessons and practice

- Workstation and terminal orientation; paths, files, and safe command habits.
- Python installation, interpreter selection, virtual environments, and dependency installation.
- Git basics, readable Markdown, notebooks versus scripts, and reproducible runs.
- Reading errors, running tests, and recording progress without claiming unrun checks.

**Practice milestone:** follow the setup in the [root README](../README.md), run both introductory examples, and execute the test suite. **Status:** setup instructions are present; a full module lesson set remains to be authored.
