# Project Portfolio

Projects build on course concepts. Do not mark one complete just because a demo runs: include reproducible setup, architecture, source, sample data, tests, expected behavior, evaluation, limitations, and improvements. Use synthetic/sanitized data; never include credentials or private customer/network records.

| Level | Project | Core learning | Acceptance evidence |
|---|---|---|---|
| Beginner | Python calculator | Functions, input validation, tests | Clear invalid-input behavior and unit tests |
| Beginner | CSV data analyzer | Files, data types, summaries | Reproducible sample CSV and documented output |
| Beginner | Network log parser | Parsing, structured records | Sanitized fixtures and malformed-line tests |
| Beginner | Data visualization dashboard | Aggregation, visualization | Clearly labeled plots and data caveats |
| Intermediate | ML classifier | Splits, baseline, metrics | Holdout evaluation and error analysis |
| Intermediate | Network anomaly detector | Telemetry, unsupervised methods | Synthetic telemetry, false-positive analysis |
| Intermediate | Traffic forecasting model | Time-series validation | Time-ordered split and naive baseline |
| Intermediate | Text classification system | NLP, labels, evaluation | Reproducible corpus and per-class metrics |
| Advanced | Neural network from scratch | Tensors, gradients, optimization | Numerical gradient checks and baseline comparison |
| Advanced | Transformer implementation | Attention and tensor shapes | Tiny deterministic data and shape tests |
| Advanced | Document RAG assistant | Ingestion, retrieval, grounding | Retrieval metrics, source-linked answers, refusal cases |
| Advanced | LLM troubleshooting assistant | Prompting, RAG, evaluation | Synthetic incidents and reviewed answer quality |
| Advanced | Tool-using AI agent | State, tools, permissions | Mock tools only, bounded steps, approval gate |
| Expert | Production AI application | API, tests, observability | Deployment/runbook, monitoring, rollback plan |
| Expert | Multi-agent workflow | Orchestration, coordination | Measured task quality and failure containment |
| Expert | AI observability platform | Trace/evaluation/monitoring | Auditable traces with privacy-conscious retention |
| Expert | Secure cloud AI deployment | Identity, networking, supply chain | Threat model, least privilege, cost controls |
| Expert | AI-assisted network operations platform | Telemetry, RAG, safe workflows | Read-only by default; explicit human approval before any change |

The four first beginner projects and later project specifications will be developed in their corresponding project folders as prerequisites are taught. The repository does not yet contain those full project implementations.
