# Project instructions

This is an offline-first educational companion, not an autonomous AI system.
Preserve existing learner files; never overwrite generated artifacts without approval.
Use Python 3.11+, type hints, small functions, explicit errors, and focused tests.
Teach the conceptual foundation before abstraction. Show expected output and explain mistakes.
Never execute learner-supplied code or arbitrary shell commands from the application.
Network lessons must use simulations or read-only operations and fictional infrastructure.
Never add credentials, paid-service requirements, or automatic package installation.
Do not claim a roadmap topic has a lesson until its lesson files actually exist.
Run the checks in README.md when changing Python code or notebooks.
Future lesson generation must use exclusive file creation or request overwrite approval.
