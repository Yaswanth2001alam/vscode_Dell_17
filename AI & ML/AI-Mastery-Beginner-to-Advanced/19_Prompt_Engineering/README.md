# 19 — Prompt Engineering

**Stage:** Advanced application · **Prerequisites:** 17 · **Estimate:** 12-20 hours

## Outcomes

Design, test, and version model instructions while treating outputs as uncertain and untrusted.

Task framing; context and examples; structured outputs; decomposition; tool instructions; prompt regression tests; prompt injection and boundaries; cost and latency; evaluation rather than prompt folklore.

**Practice milestone:** produce a small versioned prompt benchmark and report failures. **Status:** planned; provider-specific details will be date-checked when authored.
