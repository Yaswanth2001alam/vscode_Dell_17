# 09 — Supervised Learning

**Stage:** Intermediate · **Prerequisites:** 08 · **Estimate:** 25-40 hours

## Outcomes

Select, fit, evaluate, and compare models that learn from input/target examples.

## Planned lessons

Linear and logistic regression; k-nearest neighbors; naive Bayes; decision trees; random forests and boosting; support vector machines; multiclass and multilabel tasks; precision, recall, ROC/PR, calibration, and threshold choice.

**Practice milestone:** compare interpretable baseline and ensemble on held-out data and justify error tradeoffs. **Status:** planned; no lessons completed.
