# Glossary

This is a growing course glossary. Definitions are intentionally short; use linked lessons for mechanisms, assumptions, and examples.

| Term | Definition |
|---|---|
| AI (artificial intelligence) | A broad field concerned with building computational systems that perform tasks associated with intelligent behavior. |
| Algorithm | A specified procedure for transforming inputs into outputs or actions. |
| Artificial general intelligence (AGI) | A debated term for AI with broad, flexible capability across many domains; there is no universally accepted operational threshold. |
| Classification | A prediction task whose output is one or more discrete categories. |
| Data | Recorded observations, measurements, or symbols used by or produced by a system. |
| Feature | An input variable or representation used by a model. |
| Generalization | Performance of a learned system on appropriately unseen examples from its intended use setting. |
| Generative model | A model that learns patterns enabling it to produce new samples or sequences. |
| Inference | Applying a trained or specified model to inputs to produce predictions or outputs. |
| Label | A target value associated with an example in supervised learning. |
| Machine learning (ML) | A set of methods that infer useful patterns or decision rules from data or interaction rather than specifying every case manually. |
| Model | A parameterized or rule-based representation that maps inputs to outputs. |
| Parameter | A learned value within a model, such as a weight in a neural network. |
| Reinforcement learning (RL) | A family of methods for learning behavior from interaction and reward signals. |
| Rule-based system | A system that applies explicit human-authored conditions or rules. |
| Training | Fitting model parameters or structure using data or interaction. |
| Validation set | Data used during model development for choices such as hyperparameters; it should not be confused with a final untouched test set. |
