# 22 — AI Agents

**Stage:** Advanced application · **Prerequisites:** 17, 21, 30 basics · **Estimate:** 25-45 hours

## Outcomes

Construct bounded model/tool workflows with explicit state, permissions, observability, and human review.

## Planned lessons

Tool calling; planning; state machines and workflow orchestration; memory; multi-agent tradeoffs; human-in-the-loop approvals; evaluation and tracing; retries and limits; prompt injection defenses and permission boundaries.

**Practice milestone:** complete a mock-tool agent that cannot perform side effects without approval. **Status:** planned; no live credentials or write-capable tools in beginner labs.
